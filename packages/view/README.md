# @vue-mcp-apps/view

Run Vue components as MCP App views (inside a host's iframe) or mount them natively in your own Vue app.

Part of [vue-mcp-apps](https://github.com/JuanmanDev/vue-mcp-apps) — write MCP Apps as native Vue components.

- Docs: [README](https://github.com/JuanmanDev/vue-mcp-apps#readme) · [Architecture](https://github.com/JuanmanDev/vue-mcp-apps/blob/main/docs/ARCHITECTURE.md) · [API reference](https://github.com/JuanmanDev/vue-mcp-apps/blob/main/skills/vue-mcp-apps/references/api.md)
- Live demo: https://juanmandev.github.io/vue-mcp-apps/

```bash
npm i @vue-mcp-apps/view
```
