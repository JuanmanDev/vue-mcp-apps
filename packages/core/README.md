# @vue-mcp-apps/core

The card contract shared by MCP servers, views and hosts: manifests, actions, protocol constants. No DOM, no dependencies.

Part of [vue-mcp-apps](https://github.com/JuanmanDev/vue-mcp-apps) — write MCP Apps as native Vue components.
